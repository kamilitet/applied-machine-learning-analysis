# Datasets

This repository uses two public datasets from the UCI Machine Learning Repository.

## Bike Sharing

- File used here: `hour.csv`
- Original dataset: **Bike Sharing** by Hadi Fanaee-T (2013)
- DOI: https://doi.org/10.24432/C5W894
- UCI page: https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset
- License: **CC BY 4.0**

The dataset contains hourly bike-rental counts for 2011–2012 together with calendar and weather variables.

## Statlog (Landsat Satellite)

- Files used here: `satellite_train.csv`, `satellite_test.csv`
- Original dataset: **Statlog (Landsat Satellite)** by Ashwin Srinivasan (1993)
- DOI: https://doi.org/10.24432/C55887
- UCI page: https://archive.ics.uci.edu/dataset/146/statlog+landsat+satellite
- License: **CC BY 4.0**

The original dataset contains 36 integer-valued spectral features and one class label. The CSV files in this repository use generic column names `V1`–`V37`, where `V37` is the class label.
